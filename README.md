  ### 🤖 Product Returns Agent
  AI-powered returns processing system demonstrating agentic orchestration. Accepts natural language requests, extracts structured information via LLM, applies YAML-driven business rules, and generates tone-adaptive customer responses.

  **Stack:** React, Node.js/Express, Google Gemini, Supabase

  **Key Features:**
  - 💬 Multi-turn conversation with context accumulation
  - 🎛️ Constrained LLM architecture (facts fixed, tone adapts)
  - ⚙️ Config-driven YAML rules engine for eligibility and routing
  - 🛡️ Edge case handling (off-topic, injection detection, vulnerable customers)
  - 📋 Full audit trail logging for compliance

  [📂 Source](https://github.com/RichJacobs69/product-returns-agent)
